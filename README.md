# hxwl-10 考古探方记录 · 出土物交接台

遗址探方、地层关系与出土物坐标档案；现场与库房共用一套可续作的出土物交接台账。

## 技术栈

React + Vite + TypeScript + CSS；领域逻辑为纯函数引擎（`src/domain/`），UI 与 Node 自测共用同一套代码。

## 本地运行

```bash
npm install
npm run dev      # 开发端口 5110
npm test         # 交接场景自测（126 项断言）
npm run test:ui  # 组件挂载冒烟
npm run build    # 类型检查 + 生产构建
```

## 交接台模型

三类记录接成一条流水线：

1. **出土物总台账**（`docs`）：一件出土物当前归属的周转箱。现场、库房各持一份副本，在线操作直写主台账，离线只记本地账。
2. **现场装箱登记**（`assignments` 的 planned/stale）：规划器按重量与易碎等级分配箱与柜位——箱防护等级 ≥ 物易碎等级、柜安保等级 ≥ 箱等级，校验承重；满柜（无空槽/无承重）进入排队，空出柜后续作出队。
3. **库房入库登记**（`assignments` 的 stored）：交接批次执行时生成，冻结入库当时的 catalog 版本、箱柜等级与槽位快照。

### 可续作交接批次

- 批次以**箱为粒度**、每箱分 `装箱登记 → 占柜位 → 入库确认` 三段检查点；中断后续作只重试未完成的箱，已完成箱零重试。
- 占柜位以"物理占用"（`placements[boxId]`）为幂等键：**写入失败**（未生效）重试安全；**回执丢失**（已生效）重放时识别既成占用，绝不重复占库位。
- 批次携带规划依据指纹；中途改归属、改等级容量导致方案漂移时，活动批次标记 `invalid`，必须重算并重建，禁止拿着旧快照续作。

### 离线合并（向量时钟）

- 节点断网瞬间冻结各件台账的向量时钟基线；离线改动只在本地累计。
- 回连后**逐件合并**：主台账较新则本地改动作废，本地较新则快进，并发且结论一致则合并时钟。
- **同一出土物两边换箱不同**：保留两版（现场版/库房版连同各自向量时钟），物件隔离、登记挂起，由**保管员裁决**后留痕落账。

### 等级/容量变更

- 箱或柜的等级、承重、槽位变更即 bump `catalogVersion`：全部待入库登记置 `stale` 并携带失效原因，重算后恢复；活动批次失效。
- **已入库记录保留当时依据**（冻结快照），不追溯挪动；稽核以 warn 提示保管员处理事后漂移。

### 一致性稽核

任何动作后跑六条不变量（`src/domain/invariants.ts`），页面顶栏实时亮灯：
一物不占两箱、一箱不抢一位、承重/槽位不超限、等级合规、入库登记与物理占用一致且冻结齐全、排队登记不悬空。

## 目录

```
src/domain/   types 模型 · util 种子/工具 · planner 装箱规划 · store 状态机 · invariants 稽核 · view 展示派生
src/components/ TopBar 节点/故障/稽核 · Ledger 总台账 · PackingPanel 装箱柜位
                BatchPanel 交接批次 · Conflicts 裁决台 · MasterData 等级容量 · StoredRecords 冻结登记 · LogPanel 流水
scripts/      selftest.mjs 场景自测 · ui-smoke.mjs 挂载冒烟
```

状态保存在 `localStorage`（`hxwl-handover-state-v1`），顶栏可"重置台账"。故障注入（写入失败 / 回执丢失）用于现场演示中断与幂等续作。
