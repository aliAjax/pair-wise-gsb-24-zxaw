# hxwl-10 出土物交接台

现场端、库房端各记一套出土物记录，交接台把**现场记录 / 交接记录 / 库房台账**三类记录接成可续作的流水，解决交接中断导致的"一件出土物占两个周转箱、两箱抢同一库位"。

## 技术栈

React + Vite + TypeScript + CSS，领域引擎为纯 TypeScript（`src/domain/`），Vitest 覆盖核心规则。

## 本地运行

```bash
npm install
npm run dev        # 开发端口 5110
npx vitest run     # 引擎测试
npm run build      # 生产构建
```

## 交接台规则

- **装箱**：按重量与易碎等级分箱——先取"够用即可"的最低防护等级箱（高等级箱留给高等级器物），同等级内 best-fit 承重；装不下的器物列入未装箱。
- **柜位分配**：封箱登记时按箱防护等级分配库位（等级匹配 + 箱数/承重上限），满柜的箱进入排队，等级上调或库位空出后自动补位。
- **离线合并**：断网后两端各自记录移箱改动，回连逐件合并；同一出土物两边换入不同箱 → 两版保留，保管员裁决后另一版释放。
- **断点续作**：入库按批写入，中断后只重试未完成的箱；以"箱@库位"为幂等键，重放批次（含应答丢失场景）不会重复占库位。
- **失效重算**：库位或箱子等级一变，引用它们的待入库登记即失效并按新依据重算；已入库记录保留当时依据快照，不回改。

## 目录

```
src/domain/    类型、装箱、柜位分配、离线合并、幂等台账、交接台编排、种子数据
src/ui/        三端记录对照、装箱台、库位与排队、待入库登记、冲突裁决、库房台账、交接日志
```
